UI/UX 부트캠프를 수료하며 세 개의 개인 프로젝트를 진행했습니다. 실무 경력이 없는 신입이기 때문에, 화면의 화려함보다 문제를 어떻게 발견했고, 어떤 근거로 결정했으며, 무엇이 부족했는지를 숨기지 않고 보여주는 것을 목표로 했습니다.

모든 프로젝트에서 실제 사용자 리서치를 대체한 방법(공개 자료 분석, 비공식 인터뷰 등)은 각 프로젝트 페이지 상단의 리서치 항목에 투명하게 밝혔습니다. 가짜 지표나 과장된 성과 대신, 정성적이고 방향성 있는 결과만 기재했습니다.

이런 협업을 잘합니다

  • 문제정의 단계에서 "왜"를 여러 번 되묻는 것
  • 디자인 결정의 근거를 문서로 남기는 것
  • 완성도보다 사용자 관점의 우선순위를 먼저 따지는 것
